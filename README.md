# VIMOON

Static, bilingual (Chinese and Vietnamese) menstrual cycle tracking prototype.

## Publish with GitHub Pages

Push the `main` branch to GitHub. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The workflow in `.github/workflows/pages.yml` publishes the site on every push to `main`.

All cycle records and settings are stored in each visitor's browser using local storage. They are not uploaded to this repository or synchronized between devices.
